# Rating rubric

Rate each item against this rubric and nothing else. Do not score generic quality, polish or
popularity. An item scores high only if it is useful for these topics:

- harness engineering
- multi-agent orchestration
- evals
- maker-checker loops
- model routing and cost
- guard rails for accounting-firm AI consulting

Scale: 1-10. 1-3 is off-topic or noise, 4-6 touches the topics in passing or is decent but mostly known already, 7-8 is a clear and
useful treatment of one or more of them, 9-10 is something a consultant would act on this week.

Verdicts: `watch` (worth the full time), `skim` (read the summary, maybe jump to a section),
`skip` (not worth the time).

Diamond in the rough: an item is a diamond when it is high-signal, early and low-noise. It
scores well on the rubric, it has little attention so far, and it is concrete rather than hype.
Set `diamond` to true only when all three hold and say why in `diamond_reason`.
